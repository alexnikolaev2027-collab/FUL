# Учёт топлива (Flet → APK)

Мобильное приложение для учёта расхода топлива: гараж машин, записи за день,
сводка месяца, автоматический перенос остатков между месяцами,
экспорт в Excel в том же виде, что исходный шаблон.

## 1. Установить инструменты (один раз)

1. Python 3.12+ — https://www.python.org/downloads/
2. Flutter SDK — https://docs.flutter.dev/get-started/install (нужен для сборки)
3. Android Studio — https://developer.android.com/studio
   (при установке отметьте Android SDK; затем один раз выполните
   в терминале: `flutter doctor --android-licenses` и примите лицензии)

## 2. Запустить приложение на компьютере (проверить)

    pip install flet openpyxl
    flet run

## 3. Собрать APK

    flet build apk

Готовый файл появится в папке `build/apk/` — скопируйте на телефон и установите
(разрешите установку из неизвестных источников).

Для Google Play соберите AAB: `flet build aab`

## Альтернатива без установки Flutter: сборка в облаке

Загрузите эту папку в репозиторий GitHub и запустите workflow
«Build APK» (файл .github/workflows/build-apk.yml) — через несколько
минут APK будет доступен в артефактах запуска.

## Как пользоваться

1. Откройте приложение, нажмите иконку гаража в шапке → «Добавить и настроить».
2. Заполните параметры авто: нормы расхода, ёмкость бака и **стартовые**
   показания спидометра и остатка топлива (один раз).
3. Каждый рабочий день вносите данные на вкладке «Запись» — расход и остаток
   считаются автоматически.
4. Остаток и спидометр переносятся между месяцами сами (28/30/31 день — неважно).
5. Вкладка «Сводка» → «Экспорт в Excel» выгрузит файл месяца в формате шаблона.
